# Ejercitación de Diseño de Software: Patrones de Diseño

- **Alumno/a:** [Tu nombre]
- **Materia:** Diseño de Software
- **Lenguaje:** Java 21
- **Entorno:** Visual Studio Code

## Descripción

Repositorio con la ejercitación de la materia: 3 unidades de 20 ejercicios cada una (60 en total). En cada ejercicio se deduce y aplica el patrón de diseño correcto (Singleton, Factory Method u Observer). Cada carpeta de ejercicio incluye su código fuente y un `README.md` con la explicación, la justificación del patrón, el diagrama UML y la evidencia de ejecución.

## Estructura

```
unidad-N/
├── README.md                     (tabla de los 20 ejercicios)
├── bloque-a-ejercicios-01-10/
│   └── ejercicio-XX-tema-patron/
│       ├── README.md
│       ├── src/
│       └── docs/                 (UML y capturas)
└── bloque-b-ejercicios-11-20/
```

## Cómo ejecutar un ejercicio

Desde la carpeta del ejercicio:

```bash
javac -d out src/*.java
java -cp out Main
```
